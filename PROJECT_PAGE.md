# HuMiT project page

The arXiv project page is in [`docs/`](docs/), copied from the existing [HuMiT project page](https://humit-ral.github.io/) and updated with the authors and affiliations supplied by the project team. The original page credits the [VideoMimic](https://videomimic.net/) template.

The `[paper]` and `[arXiv]` buttons currently link to an arXiv title search. Replace both URLs in [`docs/index.html`](docs/index.html) with the final paper and abstract URLs when available. The `[code]` button currently links to this repository and can be updated there as well.

To publish with GitHub Pages, select the `arxiv-project-page` branch and `/docs` as the source in the repository's Pages settings.
