# HuMiT project page

The arXiv project page is in [`docs/`](docs/), copied from the existing [HuMiT project page](https://humit-ral.github.io/) and updated with the authors and affiliations supplied by the project team. The original page credits the [VideoMimic](https://videomimic.net/) template.

The `[paper]` button opens the named preprint at [`docs/humit.pdf`](docs/humit.pdf). The `[arXiv]` button still links to an arXiv title search; replace that URL in [`docs/index.html`](docs/index.html) when the abstract URL is available. The `[code]` button currently links to this repository and can be updated there as well.

The page is published at <https://xiaohu-art.github.io/Track/> from the `arxiv-project-page` branch and `/docs` source.
